# Context

ADR 0008 はツールバーの下に固定高さのステータスバーを常設し、メッセージが無いときは
保存先を表示していた。しかし常設のバーは常に約 22pt を占有し、スクラッチパッドでは
キャンバスを広く取る方がよい。操作結果は一過性の情報で、古いメッセージを残す必要もない。

一方で、保存・コピー・背景の貼り付け・最前面の切り替えは、無言で終わらせると
成否や保存先が分からない。結果は操作直後に見える必要がある。

キャンバス上にオーバーレイすると、ADR 0002 のスクリーンショット切り出しに写り込む。

# Decision

1. 常設のステータスバーを廃止し、ツールバーの下（キャンバス右上）に**通知**を
   一時表示する。
   - 位置はキャンバス右上から 12pt 内側。ツールバーとは重ねない。
   - 幅は最大 420pt。1行目に結果、2行目に保存先などの補足を小さく出し、
     長いパスは折り返す。
   - 成功は3秒、エラーは6秒で自動消去する。`request_repaint_after` で期限どおりに消す。
   - 通知はクリックを透過させ、キャンバスへの描画を妨げない。
2. 書き出し（⌘C / ⌘S）では、通知が表示中なら通知を描かないフレームを1フレーム挟んでから
   `request_screenshot` する。これにより出力 PNG に通知は写り込まない。
3. 保存先の常設表示は廃止し、保存ボタンのツールチップと保存成功通知の2行目で示す。

ツールバーのグループ単位の折り返し（ADR 0008 の1）はそのまま維持する。

不採用: ステータスバーを低くして残す案（常設である限りキャンバスを占有する）、
通知をキャンバスに重ねたまま撮影する案（出力 PNG に写り込む）、
通知を別ウィンドウにする案（位置合わせとフォーカスが不安定で、この用途には過剰）。

# Consequences

## Pros

- キャンバスが常に約 22pt 広い。
- 保存先や成否が操作直後に目に入り、古い表示が残らない。
- 通知はクリックを透過するので、下のキャンバスをそのまま描ける。
- 出力 PNG は従来どおりキャンバスだけ。

## Cons

- 通知は一時的にキャンバス右上を覆う。
- 保存先は常時見えない（保存ボタンのツールチップで確認する）。
- 通知の表示中に書き出すと、撮影を1フレーム遅らせる（体感できない程度）。
