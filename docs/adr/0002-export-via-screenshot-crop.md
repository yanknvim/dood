# Context

出力は PNG。解像度を「固定」にするか「画面依存」にするかで実装が大きく変わる。

固定解像度（例 3200×2000）で出すには、画面とは別にオフスクリーンで描き直す経路が必要になる。
選択肢は `egui_kittest` のヘッドレス描画、`egui-wgpu` のオフスクリーン描画、独自ラスタライザ。
`egui_skia` は 2023 年から更新が止まっており 0.37 非対応。`egui_software_backend` は egui 0.34 固定。

一方、画面に描かれているキャンバス矩形をスクリーンショットから切り出せば、
レンダラは1本のままで、見えているものと出力が一致する。解像度はウィンドウサイズと
ディスプレイの物理解像度（Retina で pt の2倍）に依存する。

エージェントに図を見せる用途では、幅 1500〜2300px 程度あれば文字は読める。

# Decision

キャンバス領域を `Context::request_screenshot` で取得し、`ColorImage::region` で
キャンバス矩形だけを切り出して PNG 化する。オフスクリーン描画は行わない。
解像度は画面依存とする。

# Consequences

## Pros

- 描画経路が1本で済み、画面と出力が食い違わない。
- 実装が最小。`request_screenshot` のコールバックで切り出して保存・コピーするだけ。
- ツールバーや枠線が混ざらない（キャンバス矩形で切るため）。

## Cons

- 出力サイズがウィンドウとディスプレイに依存し、再現性がない。
- コールバックは次フレーム以降・別スレッドで呼ばれ得るため、矩形と ppp を要求時に捕獲する必要がある。
- 要求後にウィンドウが縮むと範囲外になるため、クランプと失敗時の通知が要る。

## 差し替え条件

次のいずれかが起きたら、オフスクリーン描画（`egui_kittest` の `render` か `egui-wgpu`）に切り替える。

- 文字が潰れて読めない、または出力サイズの規格が必要になった。
- ウィンドウを画面外に置いた状態でも書き出したくなった。
- 印刷や他形式（SVG）への展開が必要になった。

切り出しは `export::crop` に閉じてあるので、差し替えはこの関数と `flush_export` の呼び出し側に限定できる。
