# Context

初期実装のツールバーは egui 既定の `selectable_label`・`Button`・18pt 角の色見本を横一列に並べただけで、次の課題があった。

- **ツールの識別性が低い**: `ペン P` / `直線 L` / `矢印 A` / `矩形 R` / `楕円 O` / `テキスト T` が文字だけで並び、ショートカット英字がラベルの一部に見えて直感的に分かりづらい。
- **選択状態の視認性が低い**: 色パレットの選択枠が 2pt の黒線（内側）だったため、黒色選択時に判別できず、白色（擬似消しゴム）も空枠に見える。
- **太さ・サイズの意味が伝わりにくい**: `2pt` / `4pt` / `8pt` の数値ラベルのみで、線の太さの視覚的プレビューがない。
- **操作の重要度・危険度が区別できない**: `戻す` / `やり直す` / `全消去` がすべて同じ灰色の標準ボタンで並び、破壊的操作である `全消去` を誤 클릭しやすい。
- **主要アクション（コピー・保存）が画面上にない**: `⌘C`（PNG コピー）と `⌘S`（PNG 保存＋パスコピー）がショートカットのみで、右端の `保存先: dood.png` はクリックできない静的ラベルだったため、初見で書き出し方法が分からない。

# Decision

Material Design 3（https://m3.material.io）の Baseline Light カラートークンとコンポーネント仕様（Toolbar / Segmented buttons / Icon buttons / Filled & Tonal buttons）を採用し、`src/theme.rs` にトークンと M3 ウィジェット描画を集約する。

1. **M3 カラートークンの適用**:
   - ツールバー背景に `surfaceContainer` (`#F3EDF7`)、キャンバス外周に `surfaceContainerLow` (`#F7F2FA`)、境界線に `outlineVariant` (`#CAC4D0`) / `outline` (`#79747E`) を用いる。
   - 選択状態に `secondaryContainer` (`#E8DEF8`) + `onSecondaryContainer` (`#1D192B`)、主要アクションに `primary` (`#6750A4`) + `onPrimary` (`#FFFFFF`)、破壊的操作に `error` (`#B3261E`) / `errorContainer` (`#F9DEDC`) を割り当てる。
2. **ベクターアイコンと Segmented Buttons**:
   - ADR 0004（外部フォント非同梱）を維持するため、ツール・操作アイコンは `egui::Painter` の幾何プリミティブで描画する。
   - 描画ツール6種と太さ3段階は M3 Segmented Button（高さ 36pt、両端ピル型角丸、選択時 `secondaryContainer` 塗り）としてグループ化し、太さボタンには実際の線幅プレビューを描く。ショートカットキーはホバーツールチップに分離する。
3. **円形カラースウォッチ＋チェックマーク**:
   - 色見本を円形スウォッチとし、選択時は外周の `primary` リングと内側のコントラスト付きチェックマーク（`✓`）で色覚特性や黒・白選択時でも一目で判別できるようにする。
4. **履歴・消去・書き出しボタンの明示化**:
   - `元に戻す` / `やり直す` はアイコンボタン、`全消去` はゴミ箱アイコン付きの Error ロールボタンとして視覚的に分離する。
   - 右端に M3 Tonal Button の `コピー`（`⌘C`）と Filled Button の `保存`（`⌘S`）を配置し、マウス操作だけでも完結できるようにする。

# Consequences

## Pros

- アイコン・形状プレビュー・色階層により、初見でも「何を描くツールか」「どの色・太さが選ばれているか」「どう書き出すか」が直感的に分かる。
- 外部アイコンフォントや画像アセットを追加しないため、単一バイナリ（ADR 0001）とシステムフォント方針（ADR 0004）をそのまま維持できる。
- キャンバス矩形（`self.canvas_rect`）の切り出し方式（ADR 0002 / ADR 0003）に影響を与えない。

## Cons

- `egui::Painter` によるカスタム描画コード（`src/theme.rs`）が増える。
- ツールバーの高さが従来の約 24pt から約 52pt に増えるため、同じウィンドウサイズでのキャンバス縦幅が約 28pt 小さくなる。
