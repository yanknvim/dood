# Context

ADR 0006 のツールバーは、描画ツール6個と太さ3個をアイコン＋日本語ラベルの
セグメントボタンにし、各ボタンに1ptの輪郭、グループ間に区切り線を置いていた。
文字ラベルと輪郭・区切り線が幅と視覚ノイズを増やし、既定の1100ptでも
書き出しグループが2段目に押し出されていた。

小さなスクラッチパッドでは、頻繁に使うツールを一目で選べることと、
キャンバスを広く取ることが優先される。文字を減らしてアイコン中心にし、
面の濃淡でグループを示す「フルアイコン・ボーダレス」の案を採用する。

- 1100ptで1段（44〜48pt）、480ptで2段（80〜84pt）に収めたい。
- 閉じる×は書き出しグループの折り返しに巻き込まず、常に1段目の右上端に置きたい。
- ツール名・キー・太さはツールチップで補う。
- 機能・ショートカット・通知・キャンバス・書き出しの挙動は変えない。

# Decision

1. **M3 のカラートークンとベクターアイコンを維持する**。ADR 0006 の
   Baseline Light のトークンと、`egui::Painter` の幾何プリミティブで描く
   アイコンはそのまま使う。外部アイコンフォントは追加しない。
2. **描画ツール6個**をアイコンのみの固定幅36×32ptボタンにする。選択中は
   `secondaryContainer` の角丸8pt塗り、非選択は透明。ツールチップに
   「ペン (P)」のような日本語名とキーを出す。
3. **太さ3個**もアイコンのみの固定幅36×32ptにし、実寸の横棒だけを描く。
   数値ラベルはやめ、ツールチップに「2pt」などを出す。
4. **色6個**は従来の円形スウォッチを `SURFACE_CONTAINER_HIGH` の角丸10ptの
   プレートにまとめる。選択リングとチェックマークは維持する。
5. **元に戻す・やり直す・消去**は枠線なしのフラットな32×32ptアイコンボタンにする。
   履歴は1つのプレート、消去は独立したプレートに置く。消去は通常無彩色、
   ホバー時だけ `ERROR`、シーンが空なら無効。
6. **ペースト・コピー**はアイコンのみ32×32pt。**保存**だけラベル付きの
   `primary` の Filled ピルとして残す。
7. **閉じる×**は書き出しグループから分離し、折り返し位置に関係なく1段目の
   右上端に固定する。`plan_toolbar` は1段目に32pt + 8ptの余白（40pt）を
   予約し、ほかのボタンと重ならないようにする。
8. **1ptの輪郭と区切り線を廃止する**。グループごとに `SURFACE_CONTAINER_HIGH`
   の角丸10ptプレート（内側余白 4×2pt、要素間隔 2pt）でまとめる。
   ツールバー下端の1本線だけはキャンバスとの境界に残す。
   明るい色のスウォッチの縁だけは例外的に `CONTROL_OUTLINE` を残す。
9. **寸法**はツールバー上下余白 4pt、プレート高さ 36pt、行間 4pt とし、
   1段44pt・2段84ptにする。1100ptでは1段、480ptでは2段に収まる幅計画にする。
10. **文字は保存ボタンだけ**。ほかの操作はアイコンとツールチップで示す。

不採用: 現行のアイコン＋ラベルを残す案（幅とノイズが増え、1100ptで1段にならない）、
枠線をさらに薄くするだけの案（ボーダレスという前提を満たさない）、
溢れたボタンをメニューに隠す案（全機能1クリックの制約に反する）、
消去を履歴と同じプレートに入れる案（破壊的操作の区別が弱くなる）、
閉じる×を書き出しグループ内に残す案（折り返しで右上端から動く）。

# Consequences

## Pros

- 既定の1100ptでツールバーが1段44ptになり、キャンバスが広がる。
- 最小幅480ptでも2段84ptに収まり、全ボタンが1クリックで使える。
- 閉じる×が常に右上端にあり、折り返しで位置が変わらない。
- 面の濃淡と選択の塗りで、文字ラベルなしでも選択状態とグループが分かる。
- グループ幅が固定値なので、折り返しと閉じる×の予約を単体テストで検証できる。

## Cons

- アイコンのみの機能はツールチップを読むまで意味が分からない。
- 太さの数値が見えない（「2pt」などはツールチップのみ）。
- 1段目の右寄せボタンの直上数ptは、egui の近接ヒット判定により
  ウィンドウドラッグではなくボタン側が反応する。移動はグループ間の余白で行う。
- `CONTROL_OUTLINE` の役割が明るい色のスウォッチの縁だけに狭くなる。
