# dood 仕様

コーディングエージェントに渡す図を、数十秒で描いて渡すための macOS / Linux 用スクラッチパッド。
ウィンドウを開き、マウスで描き、⌘C でクリップボードへ、⌘S で PNG とパス文字列を出す。

- 実装: Rust / eframe 0.37（wgpu レンダラ）
- 記録: 主要な決定は `docs/adr/` を参照

## 1. 目的

説明文で伝わりにくい「レイアウト」「矢印」「囲み」「注釈」を手描きで作り、
チャットの画像貼り付け、または画像ファイルのパスとしてエージェントに渡せるようにする。

## 2. 非目標

パン/ズーム、レイヤー、選択・移動・変形、消しゴム（白で代替）、禁則処理、
確定後のテキスト編集、図形の後編集、保存・復元・履歴、設定ファイル、
グローバルホットキー、`cargo install` での配布、SVG 等の他形式出力、
複数背景画像、固定解像度でのオフスクリーン描画、Shift による正方/正円拘束。

## 3. 利用シナリオ

1. 白紙にワイヤーフレームや関係図を描き、⌘C でチャットに貼る。
2. スクリーンショットを ⌘V で背景に取り込み、矢印とテキストで注釈して ⌘S で保存し、
   クリップボードに入ったパスをエージェントに渡す。

## 4. 画面

- ツールバーとキャンバスの2段。ウィンドウは初期 1100×800pt、最小 480×360pt。
- タイトルバーを持たない（枠なしウィンドウ）。移動はツールバーの余白をドラッグし、
  閉じるのはツールバー右端の × か `⌘W`（Linux は `Ctrl+W`）。
  macOS の `⌘Q`、Linux の `Alt+F4` でも終了できる。
- キャンバスはウィンドウの内側サイズに追従する（固定解像度ではない）。
- ツール・色・太さ・undo/redo/全消去はすべてツールバー上に常設され、**1クリック**で選べる。
  サブメニューやドロップダウンは持たない。
- 右端に「ペースト」「コピー」「保存」を常設する。「ペースト」はクリップボードを直接読み、
  画像データまたは画像ファイルを背景に取り込む（⌘V で取り込めない環境の保険）。
- ツールバーは幅が足りなければグループ単位で2段以上に折り返し、最小幅でも全ボタンが
  画面内に残る（ADR 0008）。
- 直近の操作結果は、キャンバス右上（ツールバーの下）に通知として一時表示する（ADR 0009）。
  成功は3秒・エラーは6秒で自動的に消える。ツールバーには重ならない。
  通知はクリックを透過し、キャンバスへの描画を妨げない。
- 通知は1行目に結果、2行目に保存先などの補足を小さく出す。長いパスは折り返す。
  常設のステータスバーは持たない。通知は書き出し PNG には写り込まない。

## 5. キャンバス

- 座標はキャンバス左上を原点とする pt。ウィンドウをリサイズしても既存の描画の座標は動かない。
- リサイズで広がった分は余白、狭まった分はクリップされる（モデルからは消えない）。
- 背景は白。要素は追加順に描画される（前面ほど後に描いたもの）。

## 6. ツール

| ツール | 操作 | 単キー |
|---|---|---|
| ペン | ドラッグで自由線。クリックで点 | `P` |
| 直線 | ドラッグで始点→終点 | `L` |
| 矢印 | ドラッグで始点→終点（先端は線幅に比例） | `A` |
| 矩形 | ドラッグで対角線（塗りなし） | `R` |
| 楕円 | ドラッグで外接矩形（塗りなし） | `O` |
| テキスト | クリック位置、またはドラッグで囲んだ矩形に複数行の入力欄 | `T` |

- 色は 黒・赤・青・緑・橙・白 の6色。`1`〜`6` でも切り替えられる。
- 太さは 2 / 4 / 8pt の3段。`[` `]` で増減。
- 白は背景と同じ色で塗るため、実質的な消しゴムとして使える。

## 7. テキスト

- `T` でテキストツールを選び、キャンバスをクリックすると既定幅（260pt）の複数行入力欄が出る。
- ドラッグで矩形を囲むと、その矩形いっぱいのテキストボックスを作る。入力欄の幅・高さは
  選択した矩形に合わせ、文字は矩形の幅で折り返す。ドラッグが小さすぎる場合はクリック扱い
  （ADR 0012）。
- `Shift+Enter` で改行。`Enter` で確定、`Esc` で破棄、フォーカスを外しても確定。
- テキスト入力中は単キーショートカットを入力欄に譲る。
- 空文字は追加しない。文字サイズは太さの段に連動（18 / 24 / 32pt）。
- 確定後のテキストは、選択した矩形の幅で折り返して描く（禁則処理はしない）。
- 確定後の編集はできない（取り消して描き直す）。
- 日本語入力は OS の IME に任せる。フォントは和文・欧文統合のシステムフォントを使用する
  （ADR 0011）。

## 8. 取り消し

- ストローク／図形／テキスト／背景の貼り付け／全消去のそれぞれが1段。
- 上限100段。新しい操作をすると redo は破棄される。
- 履歴はメモリ内のみで、終了時には消える。

## 9. 背景画像

- ⌘V でクリップボードの画像を取り込み、キャンバスの下敷きにする。
- 画像データだけでなく、ファイルマネージャからコピーした画像ファイルも取り込める。
  Linux のファイルマネージャは `text/uri-list`（`file:///path/to/image.png`）をテキストとして
  置くため、パスを解析して読み直す。素のパスでもよい。対応形式は PNG / JPEG / GIF / WebP / BMP。
- ⌘V のイベントが来ない環境（クリップボードの持ち主がテキスト形式を公開しない場合など）に備え、
  ツールバーの「ペースト」ボタンと `⌘⇧V` は arboard でクリップボードを直接読み、
  画像 → ファイルリスト → テキストの順に画像を探す（ADR 0013）。
- 画像の実寸に合わせて**ウィンドウをリサイズ**する（等倍で注釈できる）。
  画面に収まらない場合は縮小表示し、その旨を通知に表示する。
- 画像は出力に焼き込まれる。貼り直すと置換（1段の取り消し対象）。
- 制限: クリップボードにテキストと画像が同居し、そのテキストが画像ファイルのパスでもない場合、
  egui はテキストの貼り付けを優先するため画像は取り込まれない（ブラウザの「画像をコピー」など）。

## 10. 出力

### ⌘C（画像）

- キャンバス領域だけを PNG にしてクリップボードへ入れる。
- 解像度は画面の物理解像度に依存する（Retina では pt の2倍）。
- ツールバーや枠線は含まない。

### ⌘S（ファイル＋パス）

- 同じ PNG を出力パスへ保存し、そのパス文字列をクリップボードへ入れる。
- 保存に失敗した場合は通知にエラーを表示する（無言で失敗しない）。

### 出力パス

- 既定: `$HOME/Desktop/dood.png`（毎回上書き）
- 優先順位: `--out PATH` > 環境変数 `DOOD_OUT` > 既定
- 親ディレクトリが無ければ作成する。

## 11. ウィンドウ

- 起動時は常に最前面。`⌘⇧T` で切り替え、オン/オフは通知で知らせる。
- 閉じると即終了する（保存確認なし）。

## 12. ショートカット一覧

| キー | 動作 |
|---|---|
| `P` `L` `A` `R` `O` `T` | ツール切り替え |
| `1`〜`6` | 色 |
| `[` `]` | 太さ |
| `⌘Z` / `⇧⌘Z` | 元に戻す / やり直す |
| `⌘⌫` | 全消去（取り消し可能） |
| `⌘C` | キャンバスを PNG でコピー |
| `⌘S` | PNG 保存＋パスをコピー |
| `⌘V` | 背景画像を取り込む |
| `⌘⇧V` | クリップボードから画像を直接貼る（「ペースト」ボタンと同じ） |
| `Shift+Enter` | テキスト入力中に改行 |
| `Esc` | テキスト入力の破棄 |
| `⌘⇧T` | 最前面の切り替え |
| `⌘W` | ウィンドウを閉じる |

テキスト入力中は、上記の単キーとショートカットは入力欄に譲る。

## 13. 受け入れ基準

1. `cargo run --release` でウィンドウが開き、ツールバー・白いキャンバスが出る。
2. 6種のツールで描け、色6・太さ3・undo/redo/全消去が効く。
3. テキストを日本語で入力・表示でき、IME で確定できる。`Shift+Enter` で改行できる。
   矩形をドラッグして作ったテキストボックスの中に文字が折り返して収まる。
4. ⌘V（または「ペースト」ボタン）で画像データまたは画像ファイルが背景に入り、
   ウィンドウが画像寸法になる。
5. ⌘C の画像を他アプリに貼り付けられる。
6. ⌘S で PNG が保存され、パス文字列がクリップボードに入る。
7. 最小幅 480pt でもツールバーの全ボタンが画面内にあり、操作できる。
8. 通知がキャンバス右上（ツールバーの下）に数秒だけ出て自動的に消え、
   書き出し PNG には写り込まない。
9. `cargo test` が緑（データ層の単体テスト、ヘッドレス描画の画素検証、入力・通知の統合テスト）。
10. `cargo run --example selftest` が `target/selftest.png` と
    `target/selftest-narrow.png` を生成する。

## 14. 既知の制約

- 出力解像度はウィンドウサイズと画面の物理解像度に依存する（固定解像度が必要になったら
  ADR 0002 の差し替え条件に従う）。
- 日本語の禁則処理は行わない。テキストはテキストボックスの幅で折り返すため、
  長い語は単語の途中で切れることがある。ボックスから縦にはみ出す分はクリップされず、
  下に伸びる。
- **macSKK で母音（`a` `i` `u` `e` `o`）がかな変換されず、英字のまま入力される**
  （2026-11-12 確認）。標準の macOS 日本語 IME では発生しない。原因は `winit 0.30.13` の
  `WinitView::insert_text` が `hasMarkedText() == false` のとき何も通知しないためと考えられる。
  macSKK が `setMarkedText:` を経由せず `insertText:` を呼ぶ場合、winit は `Ime::Commit` を
  出さず、同じキーが通常の `KeyboardInput` → `Event::Text("a")` としてアプリに届く。
  アプリ側では回避していない（winit 側の修正待ち）。
- Windows は未検証（Linux は ADR 0010 の devShell で動作確認）。

## 15. 動かし方

```
cargo run --release                      # 既定の保存先は ~/Desktop/dood.png
cargo run --release -- --out /tmp/a.png  # 保存先を指定
DOOD_OUT=/tmp/a.png cargo run --release  # 環境変数でも指定できる

cargo test                    # 単体テスト＋ヘッドレス描画＋入力の統合テスト
cargo run --example selftest  # target/selftest{,-narrow}.png を生成（ウィンドウは開かない）
```

字形が無い環境では panic せず豆腐で描く（`MissingGlyphPolicy::Tofu`）。
